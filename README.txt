Blossom Yar PWA package

Upload all files and folders in this package to the ROOT of your GitHub repository.
The file index.html must be at the repository root.
Then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

IMPORTANT DATA NOTE:
The app stores records in this browser's localStorage. A GitHub Pages address is a different browser origin from opening a local HTML file, so existing records do not automatically move. Before switching, export/backup your data from the current app if an export feature is available. Do not delete the original file or clear browser data until the new hosted version has been checked.
