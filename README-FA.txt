Lilium Bank — بسته کامل نصب برنامه روی گوشی از طریق GitHub Pages

محتویات این ZIP را از حالت فشرده خارج کنید و همه فایل‌ها را مستقیماً در ریشه (Root) مخزن GitHub قرار دهید؛ پوشه اضافی نسازید.

فایل‌های بسته:
- index.html: نسخه جدید HTML ارسالی شما
- manifest.webmanifest: مشخصات نصب PWA و آیکون‌ها
- sw.js: سرویس‌ورکر، کش و پشتیبانی آفلاین
- icon-192.png و icon-512.png: آیکون‌های موردنیاز نصب

مراحل انتشار و نصب در اندروید:
۱) از اطلاعات فعلی برنامه پشتیبان بگیرید.
۲) فایل‌های قبلی مخزن را با فایل‌های این بسته جایگزین کنید و همه را در ریشه مخزن آپلود کنید.
۳) در GitHub وارد Settings > Pages شوید و مطمئن شوید انتشار از شاخه main و پوشه /(root) فعال است.
۴) پس از پایان انتشار، نشانی HTTPS سایت GitHub Pages خود را با Chrome یا Samsung Internet باز کنید.
۵) منوی مرورگر را باز کنید و گزینه «Install app / نصب برنامه» یا «Add to Home screen / افزودن به صفحه اصلی» را انتخاب کنید. نام گزینه بسته به مرورگر ممکن است متفاوت باشد.
۶) پس از نصب، برنامه را باز کنید و در صورت نیاز اجازه اعلان‌ها را از تنظیمات/بخش اعلان‌های برنامه صادر کنید.

نکات مهم:
- نصب PWA به HTTPS نیاز دارد؛ GitHub Pages این شرط را فراهم می‌کند.
- برای نصب، index.html، manifest.webmanifest، sw.js و هر دو آیکون باید کنار هم در ریشه مخزن باشند.
- اگر گزینه نصب بلافاصله ظاهر نشد، صفحه را یک‌بار بارگذاری مجدد کنید، کمی برای فعال شدن Service Worker صبر کنید و دوباره منوی مرورگر را بررسی کنید.
- پشتیبانی از نصب و اعلان‌ها به مرورگر و نسخه سیستم‌عامل بستگی دارد.
- اعلان هفتگی در پس‌زمینه فقط در مرورگرها/دستگاه‌هایی که Periodic Background Sync را پشتیبانی و اجازه می‌دهند ممکن است اجرا شود؛ زمان دقیق و اجرای آن تضمین‌شده نیست.
